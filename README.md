## Setup

Follow these steps to install the extension manually:

- Open Google Chrome
- Navigate to chrome://extensions.
- Turn on Developer mode (top-right corner).
- Click on Load unpacked.
- Navigate to the folder containing the extension files.
- Select the extension folder and click Open.

## Configuration (Options Page):

To customize the extension

- Right-click the extension (or open its details/options menu).
- Select Options.
- Customize the extension according to your preferences.
